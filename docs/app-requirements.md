# ToriNos アプリ要件

## 目的

ToriNos は Nostr を利用した日本語向け SNS クライアントである。ユーザーは公開タイムライン、フォロー中タイムライン、チャンネル、ステータスを閲覧し、Nostr 秘密鍵を登録した場合は投稿・返信・リアクション・リポスト・プロフィール編集などの書き込み操作を行える。

## 対象プラットフォーム

- Android
- iOS
- Wasm/Web

書き込み機能は `isWriteSupported` が true のプラットフォームで提供する。秘密鍵の保存、画像選択、画像クロップ、クリップボード、パスワードマネージャ連携はプラットフォームごとの実装に委譲する。

## 利用者ロール

- 未ログイン利用者
  - 公開情報を閲覧できる。
  - 書き込み操作を開始した場合、鍵作成または既存秘密鍵インポートへ誘導される。
- ログイン利用者
  - Nostr 秘密鍵を端末に保存し、署名が必要な操作を実行できる。
  - 複数アカウントを保存し、切り替えられる。

## 主要ナビゲーション

- フィード
  - フォロー中フィードとグローバルフィードを表示する。
  - 投稿作成、通知ドロワー、検索、設定、プロフィールへ移動できる。
- チャンネル
  - Nostr チャンネル一覧を表示する。
  - チャンネル詳細、チャンネルメッセージ、チャンネル内スレッドを表示する。
- ライブ
  - NIP-53 のライブ配信を一覧表示する。
  - ライブ詳細、参加者、ライブチャットを表示する。
- ステータス
  - NIP 系のユーザーステータスを一覧表示する。
  - ログイン中ユーザーはステータスを追加できる。
- プロフィール
  - 自分または他ユーザーのプロフィール、投稿、返信、リアクション、フォロー/フォロワーを表示する。
- 設定
  - アカウント、鍵、リレー、ミュート、NG ワード、カスタム絵文字を管理する。

## 機能要件

### アカウントと鍵

- 新しい Nostr 鍵ペアを生成できる。
- 既存の秘密鍵を `nsec1...` または hex 形式でインポートできる。
- 生成またはインポートした秘密鍵から公開鍵を導出し、端末に保存できる。
- 可能な環境では秘密鍵をパスワードマネージャへ保存できる。
- 初回鍵生成後、プロフィール初期設定を行える。
- 保存済みアカウントの一覧を表示し、アクティブアカウントを切り替えられる。
- 公開鍵をコピーできる。
- 秘密鍵は通常マスク表示し、明示操作で表示またはコピーできる。
- ログアウト時は現在アカウントの秘密鍵を端末から削除する。
- アカウント削除時は選択したリレーへ NIP-62 の削除要求を送信し、その後端末内の秘密鍵を削除する。

### フィード

- グローバルフィードは選択中のグローバルリレーから kind 1 の投稿を取得する。
- フォロー中フィードはフォローリストに基づいて投稿を取得する。
- フィードは過去投稿のページング読み込みに対応する。
- 投稿ごとにプロフィール、返信数、リアクション数、絵文字別リアクションチップ、リポスト数を表示する。
- 返信、いいね、いいね解除、Unicode/カスタム絵文字リアクションの追加・解除、リポスト、リポスト解除、投稿削除を行える。
- リアクションがある投稿ではチップ末尾の追加ボタン、リアクションがない投稿ではいいねボタンの長押しから絵文字を選択する。
- 1ユーザーが1投稿に付けられるリアクションは1種類とし、選択済みの場合はほかのチップを無効化して追加ボタンを表示しない。選択中のチップは解除操作のためタップ可能とする。
- 自分がいいねまたは絵文字リアクション済みの場合は、いいねボタンを選択色で表示する。絵文字リアクション済みでは長押し選択を無効化し、通常タップで現在のリアクションを解除する。
- リアクション選択のクイックメニューではUnicode/カスタムを混在させた最近使ったリアクションを表示し、いいね用ハートは表示しない。「絵文字を選ぶ」から開く単一のアプリ内ボトムシートに、標準絵文字とカスタム絵文字を横断した検索、よく使う項目、カテゴリ別一覧を統合する。初期表示とカテゴリ導線は「履歴→カスタム絵文字→標準絵文字」の順とする。標準絵文字にはUnicode Emoji 17.0のRGI絵文字シーケンスを収録し、肌色違いは修飾なしのデフォルト1パターンだけを表示する。別の「すべて表示・検索」ダイアログは設けず、利用履歴も端末に保存する。
- 引用投稿、メンション、リンク、画像、カスタム絵文字を表示できる。
- ミュートユーザーと NG ワードに該当する投稿はフィルタリングする。

### 投稿と下書き

- 通常投稿と返信を作成できる。
- チャンネル内ではチャンネル文脈の返信タグを付けて投稿する。
- 画像を添付できる。
- 添付画像は選択、クロップ、削除できる。
- 投稿先リレー設定を投稿シートから確認・変更できる。
- 下書きを保存し、後から復元できる。

### 記事

- NIP-23 の kind 30023 の記事を一覧・著者別一覧・詳細画面で閲覧できる。
- ログイン中かつ書き込み対応プラットフォームでは、記事投稿画面を開ける。
- 記事投稿画面はダイアログではなく独立した全画面として表示する。
- タイトル、概要、Markdown 本文、カバー画像、トピックを入力できる。
- カバー画像は HTTPS URL 入力または画像選択・アップロードで設定できる。
- 選択した画像を Markdown 画像記法として本文へ追加できる。
- 編集画面とプレビュー画面を切り替えられる。
- 記事一覧で選択中の記事リレーへ kind 30023 を公開する。
- 公開成功後は作成した記事の詳細画面へ遷移する。
- 自分の記事は詳細画面から編集画面を開き、既存の `d` タグと `published_at` を維持して更新できる。
- 記事用下書き、削除は今後の対応範囲とする。

### スレッド

- 投稿詳細では返信、いいね、リポストをタブで表示できる。
- スレッド内から別の投稿詳細へ遷移できる。
- チャンネル由来のスレッドではチャンネル文脈を維持して返信できる。

### チャンネル

- チャンネル一覧を表示し、メッセージ数、最終活動、最新メッセージ、未読数、お気に入り状態を扱う。
- チャンネル一覧はページング読み込みに対応する。
- チャンネルを新規作成できる。
- チャンネル作成時はチャンネルメタ情報と初回本文を公開する。
- チャンネル詳細では kind 42 のメッセージを送受信できる。
- チャンネル所有者はチャンネルメタ情報を編集できる。
- チャンネルメッセージに対して返信、いいね、リポストを行える。
- チャンネルキャッシュを削除できる。
- お気に入り以外のチャンネルキャッシュを一括削除できる。

### ステータス

- kind 30315 のステータスを表示する。
- ステータスにはタグ、本文、参照 URL、終了時刻を設定できる。
- 期限切れステータスは表示対象から除外する。
- ステータス画面でプロフィールへ遷移できる。

### ライブ

- kind 30311 のライブ配信イベントを表示する。
- ライブ一覧では live、planned、ended の状態で絞り込める。
- live 状態でも最終更新から 1 時間以上経過したイベントは終了扱いで表示する。
- ライブ詳細ではタイトル、概要、サムネイル、配信 URL、録画 URL、開始時刻、終了時刻、参加者数、参加者ロールを表示する。
- 配信 URL と録画 URL は外部ブラウザまたは OS 標準の URL ハンドラで開く。
- ライブ詳細では kind 1311 のライブチャットを表示する。
- ログイン中ユーザーは対象ライブの `a` タグを付けてライブチャットを投稿できる。
- 未ログイン利用者はライブとチャットを閲覧できるが、チャット投稿はできない。
- ライブ画面でプロフィールへ遷移できる。
- ライブ配信イベントの作成・編集、参加者 proof 検証、Meeting Spaces、Room Presence は現時点では要件外とする。

### プロフィール

- kind 0 のプロフィールを表示する。
- 名前、表示名、自己紹介、アイコン URL、バナー URL、NIP-05 アドレスを編集できる。
- アイコンとバナーは URL 入力または画像選択・クロップで更新できる。
- フォロー、フォロー解除を行える。
- フォロー数とフォロワー数を表示する。
- フォロー中/フォロワー一覧を表示し、一覧内検索ができる。
- プロフィール本文内の Nostr 参照を解決し、関連プロフィールを表示できる。
- ユーザーの参加リレー一覧を表示できる。

### 検索

- 検索リレーを利用して投稿検索とユーザー検索を行う。
- 検索結果は投稿タブとユーザータブで表示する。
- 投稿検索はページング読み込みに対応する。
- 検索結果でも返信数、リアクション数、リポスト数を表示する。

### 通知

- ログイン中ユーザー向けに通知ドロワーを表示する。
- メンション、返信、リアクション、リポスト等の通知項目を表示する。
- 未読通知がある場合はフィード上で通知状態を示す。
- 通知を開いたときに既読化できる。
- 通知からユーザープロフィールまたは対象スレッドへ遷移できる。

### リレー設定

- 既定リレー一覧を持つ。
- リレー URL を追加・削除できる。
- リレー単位で有効/無効を切り替えられる。
- フォロー中フィード、グローバルフィード、チャンネル、アーティクル、ライブ、ステータスごとに利用リレーを選択できる。
- フォロー中フィードでは「すべてのリレー」を選択できる。
- リレー設定は端末に保存する。

### フィルタリング

- ミュートユーザー一覧を管理できる。
- NG ワード一覧を管理できる。
- 非公開ミュートリストを取得・保存し、ローカルミュート/NG ワードへ反映できる。
- ミュートや NG ワードはフィード、チャンネル等の表示に反映する。

### カスタム絵文字

- ローカルのカスタム絵文字一覧を管理できる。
- 公開絵文字セットを検索できる。
- 未登録カスタム絵文字をタップした場合、該当 shortcode を検索条件にして設定画面へ遷移する。
- テキスト表示時に登録済みカスタム絵文字を画像として表示する。

### リンクプレビュー

- 投稿本文から Web URL を抽出する。
- URL のタイトル、説明、画像などを取得し、リンクプレビューカードとして表示する。
- プレビュー取得に失敗した場合でも投稿本文の表示を妨げない。

## NIP 別機能要件

NIP 対応は、公式 NIPs リポジトリの kind/NIP 対応表を基準に整理する。ここでは ToriNos の利用範囲を「対応中」「部分対応」「計画/未対応」に分ける。

| NIP | 機能 | 対応状況 | ToriNos での扱い |
|---|---|---|---|
| NIP-01 | 基本プロトコル | 対応中 | イベント署名、`REQ`/`EVENT`/`EOSE`/`CLOSE`、kind 0 メタデータ、複数リレー購読・配信の基盤として扱う。 |
| NIP-02 | フォローリスト | 対応中 | kind 3 の `p` タグをフォロー一覧として取得・更新し、フォロー中フィード、フォロー数、フォロー/解除に使う。 |
| NIP-05 | DNS ベース識別子 | 部分対応 | プロフィールの `nip05` フィールドを表示・編集する。DNS 検証結果の表示は現時点では要件外。 |
| NIP-09 | イベント削除 | 対応中 | kind 5 を投稿、リアクション、リポスト、チャンネルキャッシュ削除要求などに使う。削除反映はリレー/クライアント側の対応に依存する。 |
| NIP-10 | テキストノートとスレッド | 対応中 | kind 1 の投稿/返信で `e`/`p` タグを付与し、返信先判定、スレッド表示、返信数取得に使う。 |
| NIP-18 | リポスト | 対応中 | kind 6 を作成・表示し、リポスト数には kind 6 と `q` タグ付き引用投稿を合算する。ポスト詳細のリポストタブでは引用投稿の内容を表示する。自分のリポスト状態と解除対象は kind 6 のみとし、解除は対応する kind 6 に対する kind 5 で行う。 |
| NIP-19 | bech32 エンティティ | 対応中 | `nsec` のインポート、`npub` の表示/コピー、`note`/`nevent` の解析・生成に使う。 |
| NIP-21 | `nostr:` URI | 部分対応 | 投稿本文内の `nostr:note...` / `nostr:nevent...` を引用参照として解析する。OS/ブラウザのプロトコルハンドラ登録は要件外。 |
| NIP-23 | 長文記事 | 部分対応 | kind 30023 の記事一覧、著者別一覧、詳細表示、新規投稿、編集に対応する。本文は Markdown とし、`d`、`title`、`summary`、`image`、`published_at`、`t` タグを扱う。記事用下書き、削除、NIP-22 コメントは現時点では要件外。 |
| NIP-24 | 追加プロフィールメタデータ | 部分対応 | `display_name`、`banner` などのプロフィール項目を編集・表示する。全フィールド対応は要件外。 |
| NIP-25 | リアクション | 対応中 | kind 7 の `+`、Unicode 絵文字、NIP-30 カスタム絵文字リアクションを作成・集計表示し、自分のリアクション状態を扱う。解除は対応する kind 7 に対する kind 5 で行う。 |
| NIP-27 | テキストノート参照 | 部分対応 | 本文中の Nostr 参照をリンク/引用として扱う。全エンティティ種別の展開は要件外。 |
| NIP-28 | パブリックチャット | 対応中 | kind 40/41/42 をチャンネル作成、チャンネルメタ更新、チャンネルメッセージとして扱う。`root`/`reply` マーカー付き `e` タグで文脈を保持する。 |
| NIP-30 | カスタム絵文字 | 対応中 | `emoji` タグと kind 30030 の絵文字セットを利用し、ローカル登録済み絵文字を本文中で画像表示する。 |
| NIP-37 | 下書きイベント | 対応中 | kind 31234 を下書き保存に使う。本文・画像 URL・返信先・対象 kind を NIP-44 で自己暗号化して保存/復元する。 |
| NIP-38 | ユーザーステータス | 対応中 | kind 30315 をステータスとして表示・投稿する。`d` タグをステータスタグとして扱う。 |
| NIP-40 | 有効期限 | 対応中 | ステータスの `expiration` タグを終了時刻として扱い、期限切れステータスを表示対象から除外する。 |
| NIP-44 | 暗号化ペイロード | 対応中 | 下書きと非公開ミュートリストの自己暗号化に使う。DM 用途は現時点では要件外。 |
| NIP-50 | 検索 | 対応中 | 検索リレーに `search` フィルターを送信し、投稿検索とユーザー検索を行う。 |
| NIP-51 | リスト | 部分対応 | kind 10000 の非公開ミュートリストを NIP-44 で暗号化して保存・取得する。リスト種別全般への汎用対応は要件外。 |
| NIP-53 | ライブアクティビティ | 部分対応 | kind 30311 のライブ配信を一覧・詳細表示し、kind 1311 のライブチャットを表示・投稿する。Meeting Spaces、Room Presence、参加者 proof 検証、配信イベント作成は現時点では要件外。 |
| NIP-62 | Request to Vanish | 対応中 | アカウント削除時に kind 62 を選択リレーへ送信し、その後ローカル秘密鍵を削除する。削除の完全性は保証しない。 |
| NIP-65 | リレーリストメタデータ | 対応中 | kind 10002 の `r` タグで有効リレー一覧を公開する。プロフィール表示では他ユーザーの参加リレー一覧として取得する。 |
| NIP-94 | ファイルメタデータ | 部分対応 | 画像アップロード API のレスポンスに含まれる `nip94_event.tags` から `url` を抽出する。ToriNos 自体で kind 1063 を公開することは要件外。 |
| NIP-96 | HTTP ファイルストレージ | 部分対応 | `nostr.build` のアップロード API に画像を送信し、返却 URL を投稿本文へ付与する。アップロード先は現状固定。 |
| NIP-98 | HTTP 認証 | 対応中 | 画像アップロード時に kind 27235 の認証イベントを署名し、`Authorization: Nostr ...` として送信する。 |

### 計画または未対応の NIP

- NIP-04: 旧 DM はプッシュ通知計画上の通知対象候補として記載があるが、本体 UI の送受信機能としては未対応。
- NIP-17/NIP-59: 新しい Private Direct Messages/Gift Wrap 系 DM は未対応。
- NIP-07/NIP-46/NIP-55: 外部 signer 連携は未対応。
- NIP-57: Zap は未対応。
- NIP-92: メディア添付メタデータは未対応。現状は画像 URL を本文に追加する。

## データ保存要件

- 秘密鍵は各プラットフォームの安全な保存先に保存する。
- リレー設定、選択中リレー、ミュート、NG ワード、カスタム絵文字、ステータス表示設定などはローカル設定として保存する。
- チャンネルメッセージとチャンネル一覧情報はローカルキャッシュできる。
- 起動時にチャンネルキャッシュを整理する。

## 非機能要件

- リレー接続は複数リレーへの WebSocket 接続を前提とする。
- 接続中リレーの増減に応じて購読を再送し、既存購読を維持する。
- 画面単位で購読を開始・終了し、不要な購読を閉じる。
- 初回読み込み、ページング、ライブ更新を区別し、重複イベントを抑制する。
- 投稿、リアクション、リポストなどの操作は可能な範囲で楽観的 UI 更新を行う。
- ネットワークやリレーの一時的な失敗は画面全体のクラッシュにつなげず、ログ出力と局所的なエラー表示で扱う。
- 日本語 UI を基本とする。

## プッシュ通知
