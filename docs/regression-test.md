# ToriNos 回帰テスト

リリース前や大きな変更の後に、アプリ全体の表示と主要操作が壊れていないことを手で確認するための手順。
機能の正は [`app-requirements.md`](./app-requirements.md) とし、ここには「何をどの順で見るか」だけを書く。

各項目は `[ ]` を `[x]` に変えて記録する。不具合を見つけたら項目IDと画面のスクリーンショットを残す。

## 0. 準備

### 0.1 端末と設定

- 端末: Android 実機（縦持ち、画面幅 600dp 未満）。横長レイアウトは「11. 横長画面」で別に見る。
- OS の文字サイズ・表示サイズ: 既定値（`adb shell settings get system font_scale` が `1.0`）。
- アプリの文字サイズ: 設定 → 表示 → 文字サイズ「標準」（倍率 1.15。未設定時の既定値）。
- ライト／ダークは OS 設定に従う。基本はライトで通し、「10. 表示設定」でダークを見る。

文字サイズ別の確認では、アプリ側の段階を次の順に切り替える。

| 表示名 | 倍率 | 確認の重さ |
|---|---:|---|
| 極小 | 0.85 | 主要画面だけ |
| 小 | 1.00 | 主要画面だけ |
| 標準 | 1.15 | 全項目（既定） |
| 大 | 1.30 | 主要画面だけ |

OS 側を大きくした場合（例 `font_scale` 1.3）、アプリ設定との積は 1.6 で頭打ちになり、設定画面に「端末の文字サイズが大きいため、これ以上は大きくなりません。」が出る。

### 0.2 アカウント

- テスト用アカウントを使う。普段使いのアカウントで投稿・リアクション・削除を試さない。
- 複数アカウント切り替えを見るため、テスト用アカウントを2つ用意する。
- 実リレーに送信される操作（投稿、リアクション、リポスト、フォロー、削除、通報）は、テスト用アカウントの自分の投稿か、送信して困らない相手に限る。他人の投稿に誤ってリアクションしないよう、タップ位置は目視で確認してから押す。

### 0.3 ビルド

```sh
./gradlew :androidApp:installDebug
```

ログを取りながら確認する場合は `adb logcat` を並行して取る。

`adb shell input text` は日本語 IME が有効だとかな変換される。英字で検索するときは IME を英字入力に切り替えるか、かなで確定できる語を使う。

## 1. 表示の共通チェック（各画面で見る）

以下は 2 章以降の各画面を開いたときに毎回見る観点。画面ごとの項目では繰り返さない。

- 文字が途中で切れていない（「…」で省略される設計の箇所を除く）。
- 文字が隣の要素やアイコンに重なっていない。
- 1行に収める設計のラベル（フッター、タブ、チップ、ボタン）が2行に折り返していない。
- 固定高さの行・バーの中で文字の上下が欠けていない。
- ヘッダー・フッター・ステータスバー・ナビゲーションバーの裏に本文が潜り込んだまま操作できなくなっていない。
- ダイアログとボトムシートの本文が画面内に収まり、ボタンまでスクロールで届く。
- 画像の読み込み前後で行の高さが大きく跳ねない。

### 3.2 スクロールとヘッダー

- [ ] F-10 下へスクロールするとヘッダーとフッターが隠れ、上へ戻すと出る。途中で指を離しても中途半端な位置で止まらない。

- [ ] F-12 末尾までスクロールすると過去の投稿が追加で読み込まれる。
- [ ] F-13 引っ張って更新できる。新着が上に足され、表示位置が飛ばない。
- [ ] F-14 長くスクロールしてもカクつかない（目安として数百件）。
- [ ] F-15 アプリをバックグラウンドへ送り、5秒以内に戻すと位置がそのまま。数分後に戻すと位置を保ったまま空白期間が埋まる。10分超で戻すと最新へ戻る。

### 3.3 操作（テスト用アカウントの自分の投稿で）

- [ ] F-18 「絵文字を選ぶ」のボトムシート: 検索、履歴→カスタム絵文字→標準絵文字の順、カテゴリ移動。シートの見出しと「絵文字セット」が1行に収まる。
- [ ] F-19 リアクション済みの投稿では他のチップが無効になり、自分のチップのタップで解除できる。
- [ ] F-20 リポスト／リポスト解除。
- [ ] F-21 投稿メニューから削除できる。確認ダイアログの文言が収まる。
- [ ] F-22 通報ダイアログで理由を選べる（送信は送信して困らない投稿に限る）。
- [ ] F-23 ミュートしたユーザー、NG ワードを含む投稿がフィードから消える。
- [ ] F-24 プロフィール・通知のドロワーを開いたままシステムの戻るを押すと、ドロワーの中を1つ戻り、最後にドロワーが閉じる。裏の画面は戻らず、アプリ終了の案内も出ない（Android）。
